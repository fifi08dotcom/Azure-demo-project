# Adventure Works Data Engineering Project

This is an Azure End-to-End Data Engineering project built using the Adventure Works dataset. It covers the complete data pipeline - from data ingestion to transformation and reporting.

## Tools Used
- Azure Data Factory
- Azure Databricks (PySpark)
- Azure Data Lake Storage
- Power BI

## Project Overview
Raw data was extracted, transformed, and loaded (ETL) using Azure services, and a Power BI dashboard was created at the end to generate insights.

## Files
- `data/` - Dataset (CSV files)
- `notebook.ipynb` - Data transformation and analysis code
